Keyboard Interaction Time-Series Analysis📌 Table of ContentsAbout the ProjectResearch QuestionDatasetAnalysis WorkflowResultsVisualizationsProject StructureInstallation and ExecutionLimitationsFuture ImprovementsAttribution and License🔍 About the ProjectKeyboard Interaction Time-Series Analysis is a small Human-Computer Interaction (HCI) lab project that studies variations in keyboard timing measurements using Python.The project uses the CMU Keystroke Dynamics Benchmark to analyze how long a key is held down across repeated typing trials.Two complementary analytical methods are used:Main objective: Learn how statistical analysis, visualization, and signal-processing techniques can be applied to keyboard interaction data.This project is for educational and analytical purposes. It does not implement a keystroke-based authentication system.🎯 Research QuestionHow can time-domain statistics and frequency-domain analysis characterize variation in a keyboard timing feature across repeated typing trials?The analysis focuses on the hold duration of the period (.) key for one participant in one session.📁 DatasetCMU Keystroke Dynamics BenchmarkThe dataset was developed for research into keystroke dynamics and contains:Dataset propertyDescriptionTotal records20,400Participants51Sessions per participant8Repetitions per participant400Repetitions per session50File formatCSVFeatures UsedFeatureMeaningsubjectIdentifies the participantsessionIdentifies the sessionrepRepetition number within a sessionH.periodHold duration of the period keyDataset InstallationThe dataset is not included in this repository.Download it from the official CMU dataset source and place it at:data/DSL-StrongPasswordData.csv

Data PreparationThe dataset is loaded using Pandas. The notebook selects:Participant: s002Session: 1Feature: H.periodObservations: 50Repetition range: 1–50The observations are sorted by repetition number, and missing feature values are checked.2. Time-Domain AnalysisThe selected hold durations are summarized using descriptive statistics.The mean represents the average hold duration, while the standard deviation describes how much the measurements vary around the mean. The minimum, maximum, and median provide additional information about the distribution.A line plot displays the measurements in repetition order, with a horizontal line indicating the mean.Generated file: outputs/time_domain_H_period.png3. Frequency-Domain AnalysisThe ordered sequence is processed using SciPy and NumPy.Processing stepPurposeLinear detrendingRemoves the estimated linear trendHann windowReduces spectral leakageReal FFT (rfft)Computes the frequency-domain representationFrequency bins (rfftfreq)Identifies the corresponding frequenciesAmplitude calculationEstimates the strength of spectral componentsPeak detectionFinds the strongest nonzero componentThe frequency with the highest nonzero amplitude is selected, and its reciprocal is used to calculate the approximate period in repetitions.Generated file: outputs/fft_H_period.pngImportant: These observations are indexed by password repetition, not by uniformly sampled continuous time. Consequently, frequency is expressed in cycles per repetition, not hertz. A spectral peak does not prove the existence of a continuous typing rhythm or stable behavioral cycle.📊 Results and FindingsThe following results were obtained from participant s002, session 1.Time-Domain ResultsMetricResultNumber of observations50Mean hold duration111.288 msStandard deviation15.222 msMinimum hold duration77.600 msMaximum hold duration149.100 msMedian hold duration111.800 msInterpretation: The average hold duration was approximately 111.3 milliseconds.
